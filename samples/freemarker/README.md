# Freemarker Template Samples

Sample templates for the [generic generator](https://contextmapper.org/docs/generic-freemarker-generator/) ("Generate Text File with Freemarker Template"):

* `markdown-templates`: Markdown reports (full report, glossary, Bounded Context lists, flows, state transitions)
* `jhipster`: JHipster Domain Language (JDL) files for monoliths and microservices
* `csv-files`: CSV exports of stakeholders and value registers
* `sample-models`: CML models to try the templates with
